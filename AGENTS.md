# Honasa Consumer — Global Beauty Ecosystem

This repository contains the web experience prototype for Honasa Consumer Ltd. and its house of brands:
- Mamaearth
- The Derma Co.
- Aqualogica
- BBlunt
- Dr. Sheth's
- Staze
- Luminéve
- Reginald Men

Built with Vite, React, TanStack Start & Router, and Tailwind CSS.
